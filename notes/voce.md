# Textul de citit — vocea videoului (varianta 4)

**Cum înregistrezi:**
- telefonul la ~20 cm, cameră mică și liniștită (fără ecou), aplicația de reportofon, cel mai bun format pe care îl are;
- **un fișier pe paragraf**, numit `s01.m4a`, `s02.m4a`… (dacă greșești, reiei doar paragraful acela);
- 1 secundă de liniște la începutul și la sfârșitul fiecărui fișier;
- citește **rar și calm**, ca și cum ai explica cuiva de lângă tine; nu te grăbi, tăiem eu imaginea după voce;
- `/` = pauză scurtă, `//` = pauză lungă; **bold** = accent.

Pronunție: Raiffeisen = „RAI-fai-zen” · lei = „lay” · 8,307 = „eight thousand three hundred and seven” ·
8,500 = „eight thousand five hundred”.

---

**s01 (țintă ~14 s)**
This payslip says **eight thousand five hundred** lei take-home. / It should say **eight thousand three hundred and seven**. //
An analyst finds that by hand / — by our own timing, about **twenty minutes** of reading, recalculating and cross-checking. //
Every file. / Even the honest ones.

**s02 (~12 s)**
ORB runs those checks in **twenty seconds**; / the analyst reviews the evidence, / not the paperwork. //
Our estimate for these twenty-one files: / **seven hours**, / down to about **twenty minutes**.

**s03 (~30 s)** — ultima frază o completăm după filmare, cu timpul de pe cronometru
Most applications are **honest** / — that's where the hours go. //
So here's an honest one, / with a real stopwatch. //
Six steps, / one job each. / Two use AI, / to read and to summarise / — and anything the AI reads **must be found in the document**, / or it's discarded. //
The four that check and score are **plain code**: / no hidden text can change the score. //
Every value linked to its source. / The analyst approves. //
Upload to decision: / **[X] seconds**.

**s04 (~32 s)**
Now **Maria** / — the payslip from the start. //
Someone applied in her name / for forty-five thousand lei. //
Her bank statement shows a **pension** / — but the payslip says she's employed. //
ORB recalculates it: / **eight thousand three hundred and seven**, / not eight thousand five hundred. //
The employer comes back **inactive** in the registry. //
And pixel analysis shows **where the payslip was edited** / — every finding drawn as a box on the document.

**s05 (~10 s)**
And what no one sees one file at a time: //
**one** bank account, / **six** applications, / **six** different names. / ORB links them.

**s06 (~18 s)**
Risk: / **very high**. / But the AI **doesn't decide**. //
The score is computed by code from the evidence, / every line explained. //
The analyst decides / — and approving a flagged file takes a **written reason**.

**s07 (~18 s)**
Before any cloud AI sees a document, / names and ID numbers become stand-ins / like "Person one" / — and a **second gate** re-scans every request before it leaves. //
ID cards and unclear photos **never go to the cloud**. //
Or, / one switch, / and it all runs **in-house**.

**s08 (~20 s)**
Sixty test applications, / real cloud AI. //
**Zero** names or ID numbers reached the cloud. //
Twelve honest applicants: / none flagged high-risk, / three sent to a human for a second look. //
Thirty-six simple forgeries: / **all caught**. //
Forgeries where every number is correct: / **three of twelve** / — that's why we want **real files** next.

**s09 (~10 s)**
And when a forgery **does** get through? //
Anyone can try, / in our public **Arena**. / Each win becomes a proposed rule / — and a **human** approves it.

**s10 (~13 s)**
Our ask: / a **hundred real files**, / beside one of your analysts, / on **your own machine**. //
Count the hours saved / and the forgeries caught. //
ORB does the checking. / **Your people decide.**
